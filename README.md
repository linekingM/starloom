# 星枢织阵 · Starloom

> **凝练麻将博弈灵魂，却完全跳脱麻将皮囊的青瓷鎏金星盘塔防游戏。**

## 设计哲学：为什么麻将好玩，以及我们如何凝练它的灵魂？

本作没有任何麻将牌面、万筒条字样或牌桌视觉，而是将麻将最令人上瘾的 **五大策略灵魂** 完全重构为原生星律塔防机制：

1. **有限公共星池与读池算律（牌山博弈）**：所有律晶均来自 **72 枚有限公共星池**（烬火/沧澜/翠林各 1–5 阶 + 晨星/蚀月/天穹三极，各 4 枚）。玩家抽取与载律蚀兽携带均消耗同一星池，随时可打开「星池余量」读池并果断转阵。
2. **流律与凝律的双重拓扑（顺子 vs 刻子）**：地图上 3 座三孔回路既可构筑同系顺阶 **流律（1-2-3 连锁清群/灼烧/减速）**，也可构筑三同 **凝律（破甲暴击重炮）**，更有第 4 枚同晶注入的 **极律升华（轨道激光 + 免费岭上星落）**。
3. **截律夺晶与隐阵博弈（吃碰杠 vs 门前清）**：载律蚀兽头顶携带星池律晶经过防线时，玩家可触发慢动作 **截律** 夺晶瞬间成阵并晕眩敌军——代价是该回路 **明锁**，放弃「无瑕隐阵 ×1.5」高倍加番！要即时救急还是忍辱守清，全在一念之间。
4. **临鸣听律与鸣誓定阵（听牌与立直）**：全阵仅差最后一晶即可完成 11 节点合鸣时进入 **临鸣状态**，实时提示多面听待鸣晶与星池余量；开启 **鸣誓定阵** 锁定布局换取全阵 +35% 攻速与 ×1.6 倍率，最终靠星池自鸣或绝杀截鸣引爆 **大合鸣**！
5. **化尘脉冲的弃牌双难（切牌艺术）**：放弃多余律晶并非白白浪费——每次「化尘」会按元素释放全场爆炎/寒潮/破甲回血/星辉震退脉冲，把「留型」与「救场」融合成极致的实时微操抉择。

```bash
npm install
npm run dev      # 开发预览
npm test         # 单元测试 + 12波 AI 平衡性模拟
npm run build    # 构建 TapTap Web / Capacitor 生产包
```
